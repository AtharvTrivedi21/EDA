## Laboratory details: (List of Experiments, Schedule, assessment policy)
1. matplotlib, seaborn, scipy and statsmodels for exploring different types
of plots and its interpretation.

2. Data Profiling and its Interpretation. Profiling tool in Python like Pandas
Profiling, describe etc.

3. Write a program which reads 500 real values and computes and displays
their (i) mean (ii) variance (iii) standard deviation. The program should
also output z-score for each value. The program should furthermore
display (i) scatter plot (ii) histograms for these numbers for n bins where
n is read from the user and (iii) density plot assuming Gaussian as the
probability density function.

4. Write a program which scans probability of k mutually exclusive and
exhaustive events. Assume any another event B. Implement Bayes’
theorem assuming these k events and event B to estimate the probability
of each of the k events assuming that the event B has already occurred.
The program should also scan (i) probability of each of the k (or k -1)
events and (ii) probability of occurrence of event B assuming that each of
the k events has occurred. Evaluate the complete probability of B given
marginal probabilities. Also calculate the probability of evens B given
individual events. Repeat the same thing on the dataset by counting and
calculating the probabilities.

5. Data pre-processing missing value handling strategies, Outliers
identification and removing, different data balancing strategies and
implementation.

6. Write a program which scans marks of 200 students in P & S. Assuming
that the students are to be graded on 5 grade-scale (A, B, C, D, and F),
display marks and grade of each student. Fit Gaussian distribution to the
data. Repeat the exercise if students are to be graded on 7 grade-scale
(A, B, C+, C, C-, D, F)

7. Hypothesis techniques on the dataset to understand the effect of
attributes on the outcomes.

8. A program to implement simple and multiple linear regression. Use the
model parameters to make prediction for the new data. Evaluate the
model on standard evaluation measures. Your program should compute and display important model statistics (all the ones which are reported
by stats models) and critically comment on these statistics.

9. Use of tableau for data visualization and representation.
